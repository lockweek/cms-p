# 📺 CMS Display — информационная панель для полноэкранного вещания

Простая и лёгкая CMS для офисных информационных экранов (ТВ, мониторы в холлах, переговорных).
Разворачивается одной командой `docker compose up -d --build`, работает полностью локально, без внешних сервисов.

## 🎯 Что это такое

**CMS Display** — это мини-CMS для информационных экранов в офисе. Она автоматически:

- 🎂 поздравляет сотрудников с днём рождения прямо на экране;
- 📢 показывает объявления в заданном диапазоне дат;
- 🖼️ крутит слайдшоу из картинок и видео, когда нет ничего важнее;
- 🎨 позволяет собрать плакат-объявление во встроенном графическом редакторе.

Система состоит из двух частей:

| Компонент | URL по умолчанию | Кто использует |
|---|---|---|
| **Дисплей** | `http://<server>:8000/display` | Открывается на ТВ / мониторе в полноэкранном режиме |
| **Админка** | `http://<server>:8000/admin` | Открывают администраторы для управления контентом |

## ✨ Возможности

### Для дисплея
- 🖥 **Полноэкранный режим** — разворачивается на любом экране, автоматически подстраивается под разрешение.
- 🎂 **Поздравления с ДР** — если у сотрудника сегодня день рождения, его ФИО и должность появляются на экране с анимацией и конфетти.
- 👥 **Группировка по 3 человека** — если именинников несколько, они разбиваются по 3 на слайд, шрифт автоматически уменьшается/увеличивается.
- 📢 **Объявления по расписанию** — картинка или видео показывается только в указанном диапазоне дат.
- 🖼️ **Fallback-плейлист** — когда нет ни ДР, ни объявлений, крутятся загруженные изображения и видео.
- 🎬 **Видео играет до конца** — переход на следующий слайд происходит по событию `ended`, а не по таймеру.
- 🎨 **7 анимаций** появления слайдов, эффект Ken Burns для картинок, пульсация и конфетти для ДР.
- 📅 **Текущая дата** в левом нижнем углу на всех слайдах.
- 🔄 **Автообновление** данных раз в 5 минут без перезагрузки страницы.
- 📱 **Адаптивность** — корректно работает на мониторах 1366×768, Full HD, 4K.

### Для админки
- 👤 **База сотрудников**: ФИО, должность, дата рождения. Полный CRUD + инлайн-редактирование.
- 📢 **Объявления**: загрузка картинки или видео + период показа + инлайн-редактирование дат.
- 🎨 **Графический редактор**: canvas 1920×1080, работа со слоями, текстом, картинками, прямоугольниками, фонами.
- 🖼️ **Галерея изображений**: мультизагрузка, превью, удаление.
- 🎬 **Видеотека**: мультизагрузка, превью, удаление.
- ⚙️ **Настройки**: длительность показа слайдов, фон слайда с ДР, режим без звука для видео.
- 🎯 **Приоритеты отображения** управляются автоматически, без ручного вмешательства.
- логин admin пароль 123 правиться в .env

## 🔄 Логика показа

Система сама выбирает, что показать, по такому алгоритму:

| Что сегодня есть | Что показывается на экране |
|---|---|
| 🎂 ДР + 📢 активные объявления | Слайды с ДР (по 3 чел.) **и** слайды с объявлениями |
| 🎂 ДР, объявлений нет | Только слайды с ДР |
| Объявлений нет, ДР нет, есть картинки/видео | Слайдшоу: картинки чередуются с видео |
| Ничего нет | Пустой слайд «Нет событий» |

> **Ключевое правило:** слайды с днями рождения показываются **всегда**, когда есть именинники. Объявления перекрывают только галерею (fallback-плейлист).
